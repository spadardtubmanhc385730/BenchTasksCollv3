# Final pool of implemented tasks

This branch collects every task marked **implemented** in the Notion **Task Tracker** / **Task Status Table**, after reviewing the newest tasks contributed on each developer branch.

Layout: `tasks/finalpool/<task-name>/` with the task's original `docs/`, `evaluation/`, `preprocess/`, `groundtruth_workspace/` and `initial_workspace/` files copied unchanged from the developer branch shown below.

Review criteria (from `tasks/examples/example-task`): non-empty, English-only `docs/task.md` and `docs/agent_system_prompt.md`; an optional `docs/user_system_prompt.md` must also be English when present; the supporting task files must exist. Tasks with Chinese prompt text or a missing evaluation entry point remain **implementing** and are not part of this pool.
